# Zetrom Utilities

Añade esta URL en Dalamud (/xlsettings → Experimental → Custom Plugin Repositories), y busca Zetrom Utilities en /xlplugins:

https://raw.githubusercontent.com/joandelahuerta/ZetromUtilities-Releases/main/repo.json

Necesita Penumbra para animaciones, Simple Heels para posición, Cammy para cámara y ChatTranslated para traducción. Desactiva cualquier copia de desarrollo antes de instalar.
